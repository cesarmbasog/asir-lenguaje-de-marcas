Mi Blog

En este espacio comparto mis aprendizajes, prácticas y experiencias durante mi formación en Administración de Sistemas Informáticos en Red. Aquí encontrarás contenido sobre programación, desarrollo web, redes y administración de sistemas.

Mis primeros pasos Con HTML y CSS

Estoy aprendiendo a crear páginas web utilizando HTML y CSS. He comenzado a trabajar con diferentes etiquetas, estructuras y propiedades para organizar el contenido y mejorar el diseño de mis páginas web. También estoy practicando la creación de diseños sencillos y adaptables.

Aprendiendo redes informáticas

Durante mi formación estoy descubriendo cómo funcionan las redes informáticas y cómo se comunican los diferentes dispositivos. Estoy trabajando con direcciones IPv4 e IPv6, máscaras de subred, protocolos y diferentes tipos de conexiones, tanto cableadas como inalámbricas.

Mis primeros pasos con JavaScript

Estoy comenzando a utilizar JavaScript para añadir interactividad a mis páginas web. He practicado con variables, operadores, condiciones y funciones. También he desarrollado pequeños ejercicios como calculadoras y programas para realizar diferentes operaciones.

Mis primeros pasos con Active Directory

Estoy aprendiendo a trabajar con Active Directory en Windows Server. Esta herramienta permite administrar usuarios, equipos y grupos dentro de un dominio. Estoy practicando la creación de cuentas, la organización de usuarios y la configuración básica de un entorno de red.

Configuración de directivas con Gpedit

Estoy descubriendo el Editor de directivas de grupo local (Gpedit), una herramienta que permite configurar diferentes opciones de Windows. Con ella puedo establecer restricciones, modificar configuraciones del sistema y controlar determinadas funciones para los usuarios del equipo.

Seguridad de Windows con Secpol

Estoy aprendiendo a utilizar la herramienta Secpol para administrar las políticas de seguridad local de Windows. Estoy explorando opciones relacionadas con las contraseñas, las cuentas de usuario, los permisos y las políticas de seguridad que ayudan a proteger el sistema.

Mis prácticas con Windows Server

Estoy aprendiendo a instalar y configurar Windows Server utilizando máquinas virtuales. Durante las prácticas estoy trabajando con diferentes herramientas administrativas, explorando sus servicios y aprendiendo cómo gestionar un servidor dentro de una red informática.

Virtualización con VirtualBox

Estoy utilizando VirtualBox para crear y administrar máquinas virtuales. Esta herramienta me permite instalar diferentes sistemas operativos y realizar pruebas en entornos independientes sin modificar directamente el sistema principal de mi ordenador.

Introducción a MySQL y las bases de datos

Estoy aprendiendo a trabajar con bases de datos utilizando MySQL. He comenzado a crear tablas, insertar información, realizar consultas y relacionar diferentes tablas mediante claves primarias y externas. También estoy practicando operaciones para organizar y gestionar información.
